# Browser Pilot 0.7.0-rc.1

Release candidate for 0.7.0. See [v0.7.0](v0.7.0.md) for the full change
description.

This candidate exists because the change set rewrites the managed skill, and the
release job runs assertions over that skill which no continuous-integration gate
reached until v0.6.2. Those assertions now run in CI, so this candidate verifies
that they also hold on a tag ref, where the version comparison is active.

## Channel behavior

- npm publishes this version under the `next` dist-tag. `npm install --global
  browser-pilot-cli` continues to resolve the current stable release.
- The `skill-stable` branch does not advance for a prerelease, so managed skill
  installations stay on the last stable commit and never see this candidate's
  compatibility metadata.
