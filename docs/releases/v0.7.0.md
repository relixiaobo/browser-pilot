# Browser Pilot 0.7.0

Browser Pilot 0.7.0 makes controls inside same-process iframes observable and
clickable without selecting the frame first. This is the first release to change
what a snapshot returns for a given page, which is why it is a minor release
rather than a patch. The CLI surface, the private Broker protocol, and the
Observation v1 element shape are unchanged, so v0.6.x Agents and integrations
continue to work.

## Frames

- A snapshot now descends into same-process iframes at every nesting depth.
  Their controls arrive as ordinary refs, including DOM-only controls the
  accessibility tree does not expose on its own, and `bp click` reaches them
  without selecting the frame first.
- Pointer coordinates compose across frame boundaries. A node reports bounds
  relative to its own document, so dispatch adds the session's offset from the
  observed root frame and the ref's offset from its document up to that root.
  Observing a single frame behaves exactly as before.
- Nested frames contribute their own accessibility trees. Without this, a plain
  `<button>` carrying no listener stayed invisible inside a frame while a
  clickable `<div>` beside it was reported, which made frame coverage
  unpredictable rather than simply absent.
- Selecting a frame still narrows observation to that frame and its own
  descendants. It never widens it to the parent.

## Frame guidance corrections

Two statements the skill made about frames were measured and found wrong.

- Selector resolution was documented as able to fall through to the top frame
  after selecting a subframe. It does not: a selector for an inner element
  resolves, and a selector naming a top-frame element fails, in both directions.
  The claim and its workaround guidance are removed.
- `bp frame` was described as the way to find what a snapshot omitted. It lists
  same-process frames only, so it can neither reveal nor select a cross-origin
  frame.

## Cross-origin frames

Cross-origin iframes run in their own browser process and are still never part
of a snapshot. Nothing in the result reports the omission, so a missing control
is indistinguishable from a control that does not exist. Reach one by finding
its source and opening it as its own page:

```bash
bp find "iframe" --attributes src
bp open "<the cross-origin src>" --new
```

## Measurement

- The capability benchmark gains a nested-frame scenario at non-zero page
  offsets on both levels. Observable target recall holds at 100% while demanding
  four more targets, and the false-interactable rate improves from 2/12 to 2/16.
- A browser-level test pins nested observation and pointer accuracy against real
  Chrome. Its action assertions read state the real element changed rather than
  treating a successful dispatch as success, because a wrong coordinate offset
  dispatches just as cleanly.
