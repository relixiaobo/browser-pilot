# Browser Pilot 0.6.2-rc.2

Release candidate for 0.6.2. See [v0.6.2](v0.6.2.md) for the full change
description.

This candidate replaces 0.6.2-rc.1, whose build failed before publication on a
release-manifest assertion that no continuous-integration gate could reach.
That assertion now spans the skill files that hold the installation contract,
and runs in continuous integration rather than only in the tag-gated release
job.

## Channel behavior

- npm publishes this version under the `next` dist-tag. `npm install --global
  browser-pilot-cli` continues to resolve the current stable release.
- The `skill-stable` branch does not advance for a prerelease, so managed skill
  installations stay on the last stable commit and never see this candidate's
  compatibility metadata.
