# Browser Pilot 0.7.1

Browser Pilot 0.7.1 makes selector commands reach the frames that 0.7.0 made
observable. In 0.7.0 a snapshot reported controls inside same-process iframes
while `bp find` and `bp locate` did not resolve selectors for those same
controls, so a command that named an element the Agent had just seen returned
nothing.

## Selector commands descend into same-process frames

- `bp find` and `bp locate` now search the selected frame and every
  same-process frame below it. A selector for a control a snapshot reported
  resolves without selecting its frame first.
- Neither command reaches upward. A selector naming a top-frame element still
  does not resolve while a subframe is selected.
- Cross-origin frames remain out of reach, unchanged. The traversal stops where
  a document becomes inaccessible, which is the same boundary a snapshot draws.
- `bp locate` reports coordinates relative to the selected frame, which is the
  space `bp click --xy` already expects, so the two compose across a frame
  boundary without adjustment.
- Element visibility and disabled state now resolve through each element's own
  document, so a control inside a frame is reported as accurately as one in the
  top document.

## Unchanged

`bp read` and `bp search` remain limited to the selected frame's own document.
They are text-oriented rather than element-oriented, and extending them raises
ordering and delimiter questions that are not settled here. The command
reference states this explicitly rather than leaving it to be discovered.
